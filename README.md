## Descripción del Proyecto

Este sistema fue diseñado y desarrollado para resolver la necesidad de un control estricto y transparente de los ingresos a la **Presidencia del Consejo de Ministros (PCM)**. Permite automatizar los flujos de autorización, gestionar las agendas de visitas y mantener un historial detallado de los movimientos de personal externo y sus respectivos acompañantes.

##  Módulos y Características Clave

* **Control de Visitas:** Registro ágil de ciudadanos, funcionarios y personal externo que ingresa a las sedes de la institución.
* **Reporte de Acompañantes:** Módulo especializado para el control y seguimiento de las personas que ingresan junto al visitante principal, garantizando la seguridad perimetral.
* **Dashboards Estadísticos:** Panel de control visual e interactivo con indicadores clave en tiempo real sobre las visitas del día, horas pico y áreas más concurridas.
* **Seguridad e Integridad:** Restricciones de acceso basadas en roles para asegurar que la información confidencial esté protegida.

##  Stack Tecnológico

* **Backend:** PHP & Laravel Framework
* **Frontend:** Blade Templates y CSS
* **Base de Datos:** PostgreSQL
